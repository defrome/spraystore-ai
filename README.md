# spraystore-ai

## Каталог товаров из Яндекс KIT

Нейронка может рекомендовать реальные товары магазина и называть актуальные цены и наличие.
Интеграция **только на чтение**: используются одни GET-запросы (в `service/kit_client.py` нет методов для других
глаголов). Заказы, клиенты, платёжные ссылки, вебхуки и вложения не трогаются.

**Включение**
1. В KIT: Настройки → API → «Сгенерировать токен» (показывается один раз; токен даёт полный доступ — храните только на бэкенде).
2. Положите его в `service/.env`: `KIT_API_TOKEN=...` (пример — `service/.env.example`). `.env` в git не попадает.
3. Первая синхронизация: `python service/catalog.py --sync`. Дальше сервис сам обновляет индекс в фоне (при старте и раз в час).
4. Посмотреть индекс: `python service/catalog.py --stats` и `python service/catalog.py --show "краскопульт для лака" --max-price 10000`;
   состояние также в `GET /api/health` (поле `catalog`).

Без токена каталог выключен, чат работает как раньше. Сбой синхронизации не роняет сервис — остаётся прошлый индекс.

**Как это работает.** Товары (`GET /v1/variants`, статус PUBLISHED + категории, характеристики, картинки) индексируются в отдельной
коллекции Chroma `products`. Перед ответом цена и наличие уточняются точечно через `GET /v1/variants/{id}` (кэш на пару минут);
если KIT недоступен, берутся данные индекса с пометкой «актуальность не проверена». Лимит KIT (3 запроса/сек) соблюдается троттлингом.
В ответе `/api/chat` появляется поле `cards` (`{id, name, price, url, image?, in_stock}`) — только для товаров, названных в ответе.

**Переменные окружения**
- `KIT_API_TOKEN` — токен KIT (пусто — каталог выключен).
- `CATALOG_MODE` — `context` (по умолчанию: товары ищутся заранее и кладутся в контекст), `tools` (модель сама вызывает
  `search_products` через function calling), `auto` (пробуем tools, при ошибке API откат на context).
- `CATALOG_SYNC_INTERVAL_MIN` — период фоновой синхронизации, по умолчанию 60.
- `CATALOG_LIVE_TTL_SEC` — кэш живых цен/наличия, по умолчанию 180.
- Дополнительно: `CATALOG_MIN_SCORE` (порог релевантности поиска, 0.70), `CATALOG_STORE_URL` (домен витрины для ссылок,
  по умолчанию `b2c_url` магазина из KIT), `CHROMA_PATH` (путь к Chroma для товаров).

**Тесты** (без сети и токена): `pip install pytest && python -m pytest service/tests`.

Следующие шаги (вне текущей версии): документы-вложения (`/v1/variants/{id}/attachments`) в RAG, похожие товары
(`/v1/products/cards/{id}/similar`).
